# PasoLibre — sitio del Proyecto 3

Sitio web académico de **Justin Peñafiel** (USFQ, Estrategias de Posicionamiento y Negocios Electrónicos, 2026).
PasoLibre es un concepto en validación: proyecta líneas de luz en el piso para ayudar a personas con Parkinson con congelamiento de la marcha.

URL pública: https://justinmate0.github.io/pasolibre/
